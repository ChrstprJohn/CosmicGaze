# Landing artwork

`galaxy.webp`, `moon.webp`, `moon-match.webp`, `age.webp`, `builder.webp`, `planets.webp`, and `gravity.webp` are WebP captures of Cosmicgaze's existing rendered discovery-card artwork. They let the homepage show the same subjects without constructing canvases, generating terrain, or downloading planet textures during scrolling. Desktop hover still opens the original live preview.

The Moon rendering uses the bundled Moon map documented by its existing source link. The builder and planet rendering use the Solar System Scope textures documented in `../textures/planets.source.json` (CC BY 4.0). Generated galaxy/orbit/gravity scenes are illustrative artwork. `cosmicgaze-showcase.webp` is the 960×540 poster from the new Cosmicgaze film in `brag-output-2026-10-16-174449/`.

Card source captures are stored in ignored `test-results/card-*.png`; no source texture files were replaced.
